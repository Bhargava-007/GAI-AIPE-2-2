# Week 1: Development Environment & First LLM Call (25CS2207E)

## Setup & Run Instructions

1. Activate the shared virtual environment from the `Practical` root:
   ..\.venv\Scripts\Activate.ps1

2. Install dependencies:
   python -m pip install -r requirements.txt

3. Create a `.env` file inside `week1-llm-call` with your OpenRouter API key:
   OPENROUTER_API_KEY=your_key_here

4. Run the script:
   python main.py
